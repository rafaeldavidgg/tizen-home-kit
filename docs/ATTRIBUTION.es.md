## Tiles de marcas (uso referencial)

Los tiles nombran servicios de terceros para lanzarlos, como hace el proyecto
base. Las marcas son de sus dueños; nada aquí sugiere aval.

- **Tile DAZN**: logo en caja de Wikimedia Commons
  (`File:DAZN LOGO.png`, CC BY-SA 4.0). Solo para referirse a la app DAZN.
- **Tile Orange TV / Orange**: wordmark de la compañía redibujado para el
  tile; Orange es marca de su dueño. Solo para referirse a la app Orange TV.
- El resto de tiles (Netflix, YouTube, …) vienen con el proyecto base upstream.
